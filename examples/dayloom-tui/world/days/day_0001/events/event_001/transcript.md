# 步入锈蚀

你推开老魏诊所那扇焊了三层铁皮的破门，生锈的铰链发出一声尖锐的呻吟。外面的空气扑面而来——机油、霉菌、劣质合成食物的焦味，还有金属锈蚀后那股挥之不去的铁腥味。头顶的隧道穹顶上，几根老旧的霓虹灯管断断续续地闪着，在积水的地面上投下紫红色的倒影。

你踏上了锈蚀之城的主街。两侧是违章搭建的金属棚屋，有的歪歪扭扭地摞在一起，像随时会塌的积木。电线像蛛网一样从头顶横七竖八地穿过，偶尔爆出几点蓝色的电火花。远处传来焊枪的滋滋声、金属锤击的回响，还有某个地下酒吧漏出来的模糊音乐。

这里的人很多——背着零件的小贩、蹲在路边抽烟的工人、裹着旧风衣快步走过的陌生人——但没有人多看你一眼。在这个地方，不看别人的眼睛，是活下去的第一条规则。

你站在街口，老魏的诊所在你身后已经隐入阴影。前方是锈蚀之城蜿蜒的主干道，两边延伸出无数岔路和小巷，像一张没有地图的迷宫。

你站在锈蚀之城的主街入口。主干道向前延伸，两旁挤满了各式摊位和店铺——左手边有个卖二手电路板的摊子，摊主是个叼着烟的瘦削中年人；右手边是一家冒着蒸汽的合成食品摊，几个工人正蹲在旁边吃早餐；更远处，一条小巷里传来有节奏的金属敲击声。主干道上人流穿梭，但所有人都步履匆匆，眼神回避。你需要选择方向，开始在这座地下迷宫中探索。

他停下来，把锤子搁在铁砧上，用搭在肩上的毛巾擦了把脸，然后才转过头来。他的眼神平静，没有恶意，只是在等你开口。
